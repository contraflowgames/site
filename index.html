About

Contraflow Games is a one-person studio making city-building and simulation games for Mac and iPad.

The name comes from traffic. Contraflow is when lanes are reversed so traffic flows the way it needs to, not the way it usually does. Most studios build for Windows first and port to Mac later, if at all. We go the other way: every game is made for Mac first, native to Apple silicon.
